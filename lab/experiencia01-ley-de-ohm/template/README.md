# Template del reporte

`template-reporte01.docx` es un documento editable de prototipo. Está diseñado
para grupos de cuatro y solicita exactamente las evidencias incluidas en la
guía y la rúbrica.

Antes de convertirlo en documento oficial se deben completar los datos de los
instrumentos, validar el montaje y confirmar la numeración de la experiencia.
