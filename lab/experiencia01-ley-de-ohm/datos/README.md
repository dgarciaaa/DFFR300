# Datos de la experiencia

La experiencia requiere:

- resistencia nominal y tolerancia;
- resistencia medida con ohmímetro;
- al menos seis pares de \(I\) y \(V\);
- rango y resolución usados en cada multímetro;
- pendiente e intercepto del ajuste \(V=mI+b\);
- diferencia porcentual entre la pendiente y la resistencia medida;
- observaciones sobre estabilidad, calentamiento y contactos.

Antes de usar la experiencia con estudiantes se debe agregar un archivo de
datos piloto fechado y revisado por el docente. No se incluyen números
simulados como si fueran resultados reales.
