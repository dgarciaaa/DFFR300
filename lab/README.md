# Laboratorio

Esta carpeta reúne los materiales de laboratorio de **DFFR300 — Física
Aplicada a las Ciencias Farmacéuticas**.

## Organización

Los materiales se organizan por experimento:

```text
lab/
├── README.md
├── experimento01-nombre/
│   ├── README.md
│   ├── slides/
│   ├── instrumentos/
│   ├── datos/
│   ├── guia-estudiante.md
│   └── rubrica.md
├── experimento02-nombre/
│   └── …
└── experimentoXX-nombre/
    └── …
```

Según las necesidades de cada experiencia, una carpeta puede contener:

- una descripción general del experimento;
- material de presentación;
- fichas o manuales de instrumentación;
- plantillas y archivos de datos;
- una guía de trabajo para estudiantes;
- criterios de evaluación.

La estructura puede simplificarse cuando un experimento requiera menos
materiales.
