 ------ es el laboratorio del curso de Fisica para quimica y farmacias ------ 

Un curso de experimentos enfocados en la fisica basica para los estudiantes  .... 
como usan un laboratorio supongo que se usará instrumentación ..... 
por ende en esta carpeta se construye un semana a semana que intenta ayudar con este material ... 

---- que pretende hacer este repo ----- 

por lo que veo se necesitará crear un breve manual de uso de la instrumentación para el experimento
de la clase en cuestion ...... 
también se necesitará explicar el experimento que se realizará por lo que abra 2 tipos de materiales por semana ... .
aun pienso si slides o una hoja de lecura impresa para su lectura .... 
a mi parecer lo mas simple son slides ya que se pude ir explicando de manera visual ... 
sin embargo, la  hoja de lectura tiene mayor ....... mmmhh ... no le veo ventaja clara ... 

gana slides para explicar ambas ideas .... 

--- entrada para construir slides ------- 

en principio se parte con un archivo tipo documento de lectura en su posibilidad o sino una idea limpia de lo que se quiere
hacer el experimento ....
para los instrumentos se intenta encontrar un archivo tipo manual a adaptar .. o sino una idea limpia con imagenes de internet
para guiar .... 

--- construccion  ------ 

a partir de eso se debe construir un clase slide breve para dar tiempo a hacer el experimento ... .
la presentacion slides-slide deber tener una estructura limpipa ... 
introduccion -> explicacion de experimento -> uso instrumentación -> a trabajar ... 

ahora bien la explicacion del experimento debe tener caracteristicas claras como el nombre del experimento ... 
quien lo hizo y porque lo hizo ... que explica o responde este experimento .... esto ayuda a motivar ... 
siempre ver cual es la pregunta que quiere responder el experimento .... 

luego el uso de la instrumentacion debe ser guiada y con la explicación de precuaciones de uso de equipo ... 
normalemnte se tienen varios intrumentos en un experimento por lo que explicar la funcion de cada instrumento 
para lograr el experimento y obtener la respuesta buscada ....
