# Ejemplos estructurales

Estos archivos son referencias de estructura y nivel de detalle:

- `ejemplo_presentacion.pdf`: referencia de jerarquía, ritmo visual, uso de
  Beamer/LuaTeX y acabado profesional.
- `ejemplo_rubrica.html`: referencia de criterios explícitos, puntajes y
  descriptores de logro.

Los ejemplos provienen de otros tópicos. No se copian sus contenidos, nombres,
autores, problemas, puntajes ni extensión. Para cada experiencia, el contenido
se reconstruye desde el syllabus, el documento semana a semana, los libros de
`general/` y los manuales de instrumentos.
